# Chiedza Games Module

This build adds a Games Library to the Quiet Arcade.

Admin:
- Open `/admin/games`
- Add, edit, activate/deactivate or delete games
- Assign each game to Calm Me, Ground Me, Let Me Rest or Help Me Return
- Choose one of four built-in game engines: Memory Match, Word Search, Pattern Match or Breathing Tap

User:
- Open Quiet Arcade
- Rooms show how many gentle games are available
- Enter a room and choose a game
- Games run inside Chiedza with no leaderboards, streaks or public scoring

Starter games are created by `npm run seed`.
